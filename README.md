# MyTani Ku

Marketplace pertanian digital Indonesia berbasis Next.js 14.

## Development

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Production build

```bash
npm run build
npm run start
```

## Deploy

Panduan deploy Vercel + Supabase ada di `DEPLOYMENT.md`.
Schema database Supabase ada di `supabase/schema.sql`.
